# YouTube Agent (Gemini)

This project carries a YouTube channel toolkit in `skills/`.
**Follow `AGENTS.md` in this repo root as your operating instructions** —
it is the router that maps each request to the right
`skills/yt-*/SKILL.md`. Read the matching SKILL.md in full before acting.

Key rules: read the voice file (`config.json` → `voice_file`) before
writing anything spoken; never invent a number; nothing publishes —
every output ends with a copyable block and the question
**ship it, or change it?**
